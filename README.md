# Contact List Manager

## About

A simple Java-based Contact List Manager that allows users to add, view, and search contacts.

## Features

- Add new contacts
- View all contacts
- Search contacts by name
- Simple menu-driven interface

## DSA Concepts Used

- **ArrayList:** Stores contact details.
- **LinkedList:** Stores matching search results.
- **Linear Search:** Searches contacts one by one.

## Technologies Used

- Java
- VS Code

## How to Run

1. Compile the program:
   `javac ContactListManager.java`

2. Run the program:
   `java ContactListManager`

- `ContactListManager.java` – Main Java source code.
